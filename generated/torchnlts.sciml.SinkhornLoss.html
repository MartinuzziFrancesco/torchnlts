torchnlts.sciml.SinkhornLoss#

class torchnlts.sciml.SinkhornLoss(reg, *, num_iters=50, reduction='mean')[source]#

Debiased Sinkhorn divergence between the state-space point clouds of a predicted and a target trajectory.

Reference: Feydy et al. (2019), AISTATS, PMLR 89, 2681; applied to chaotic attractors by Jiang, Lu, Orlova & Willett (2023), NeurIPS. Like AttractorLoss with entropy-regularized optimal transport (cost 0.5 * d^2 for Euclidean d) in place of MMD: OT(P, Q) - (OT(P, P) + OT(Q, Q)) / 2.

Gradient class: smooth (a fixed number of unrolled exp/logsumexp iterations, differentiated through).

Parameters:

  • reg – Entropic regularization strength, a single finite real number > 0 (a Python or numpy number, or a one-element tensor). Smaller values approach the exact optimal transport cost but need more num_iters and lose numerical precision.

  • num_iters – Number of Sinkhorn iterations, >= 1.

  • reduction – "mean", "sum" or "none".

Raises:

ValueError – If reg is not a single finite real number > 0, num_iters is not an integer >= 1, or reduction is not one of the three.
